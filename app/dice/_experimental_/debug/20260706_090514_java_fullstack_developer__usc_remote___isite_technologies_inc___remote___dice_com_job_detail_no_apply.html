Need someone with an active IRS MBI clearance “Job Title: Senior Systems Software Developer

Location: Remote

Duration: 1 year to start with

Clearance: IRS MBI Required

 

Position Overview:

We are seeking a highly experienced Senior Systems Software Developer with 10+ years of hands-on experience in designing, building, testing, and maintaining system-level software. This role focuses on operating systems, middleware, embedded systems, and other foundational software components that power enterprise-scale environments.

 

Key Responsibilities:

  • Design, develop, test, and optimize complex system-level software components
  • Work on operating systems, middleware, embedded systems, and core infrastructure
  • Collaborate closely with systems engineers to design scalable and secure architectures
  • Perform low-level debugging, tuning, and performance optimization
  • Ensure system reliability, resiliency, and compliance with federal security standards
  • Document architecture, workflows, and integration patterns

 

Required Skills:

  • 10+ years of professional systems-level development experience
  • Strong programming experience in Java, C, C++, and similar languages
  • Deep understanding of OS internals, memory management, and distributed systems
  • Experience with secure architecture design in the federal environment
  • Strong debugging, profiling, and performance tuning skills”.
